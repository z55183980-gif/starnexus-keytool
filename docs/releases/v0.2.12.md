# StarNexus Key Tool v0.2.12

- 使用 StarNexus 密钥时，Claude 桌面版会补全网关模型菜单。若这把密钥选择 Fable 5.2 为默认模型，菜单顺序为 Fable 5.2、Opus 5.5、Sonnet 5.5、Sonnet 4.6。
- 沿用旧配置时，桌面版体检会提示 D6，Claude Code CLI 会提示 C7。点击修复后，完全退出对应客户端并重新打开。CLI 的 `/model` 可通过网关发现模型。
- 修复保存配置或切换桌面版模型后误报「仍有外部配置或认证覆盖」的问题。

v0.2.10 可在设置中检查更新。更早版本请从官网下载安装。
